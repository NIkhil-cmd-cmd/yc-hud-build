Privacy

Tera is built local-first. Your browsing patterns, compiled workflows, and policy data remain on your machine unless you explicitly choose to share them.

What stays on your Mac

  • Observed browsing actions and compiled workflow policies
  • Embedding indexes and Markov decision process graphs
  • Token usage metrics and execution logs
  • Agent configuration and MCP integration settings

Default storage path: ~/Library/Application Support/OpenHive/

What may leave your Mac

When you run the agent (not policy replay), Tera sends task context to the LLM provider you configure in your local .env file — Fireworks, OpenAI, or others. You control which provider and model are active.

Exa search requests are sent to Exa when the agent needs to discover page schemas. This is opt-in via your API key configuration.

What we never do

  • Upload your browsing history to a cloud training pipeline
  • Sell your data or use it to build ad profiles
  • Run passive observation data through third-party analytics

Your controls

You choose whether the Python engine is running, which models connect to your workflow, and which MCP servers are enabled. Policy replay (T1 tier) executes entirely on-device with zero LLM calls.
