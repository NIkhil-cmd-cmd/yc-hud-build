## Project Name
OpenHive

## Tagline
The agent thought once. Now it never has to again.

## Description
OpenHive is a native macOS browser that learns from you. Browse normally — it passively captures actions and compiles them into an embedding-based Markov policy. Repeat tasks execute with zero LLM tokens via policy lookup.

We beat Browser Use SOTA on repeat runs: ~15 seconds and 0 tokens after one learning session vs 68 seconds and ~15k tokens every time.

Built on Nook (Swift/WebKit) with a Python policy engine. HUD grades execution. Modal parallelizes eval. Exa fills unknown page schemas.
